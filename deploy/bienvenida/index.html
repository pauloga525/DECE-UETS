Habilita la conexión segura

El sistema funciona dentro de la red del colegio con un certificado propio. Tu equipo necesita reconocerlo una vez; después entrarás directamente, sin avisos de “No es seguro”.

  1. Descarga el instalador
    Descargar instalador para Windows
  2. Ábrelo con doble clic desde la barra de descargas.
    Si Windows muestra “Windows protegió su PC”, pulsa Más información → Ejecutar de todas formas.
  3. Aparece un aviso de seguridad preguntando si deseas instalar el certificado DECE-UETS-CA: pulsa Sí.
  4. Cierra el navegador por completo (todas las ventanas) y vuelve a abrirlo.

¿Prefieres hacerlo a mano? Descarga el certificado, ábrelo → Instalar certificado → Usuario actual → Colocar todos los certificados en el siguiente almacén → Entidades de certificación raíz de confianza → Finalizar.

  1. Descarga el certificado
    Descargar certificado
  2. Ábrelo con doble clic: se abre Acceso a Llaveros. Elige el llavero Inicio de sesión y pulsa Añadir.
  3. En la lista, haz doble clic en DECE-UETS-CA → Confiar → “Al utilizar este certificado”: Confiar siempre. Cierra la ventana y escribe tu contraseña del Mac.
  4. Cierra el navegador por completo (⌘ Q) y vuelve a abrirlo.
  1. Descarga el certificado
    Descargar certificado
  2. Abre Ajustes → Seguridad (o “Seguridad y privacidad”) → Más ajustes de seguridad / Cifrado y credenciales → Instalar un certificado → Certificado de CA.
  3. Pulsa Instalar de todas formas, confirma con tu PIN o huella y elige el archivo DECE-UETS-CA.crt de Descargas.
  4. Vuelve aquí y pulsa Ya lo instalé, verificar.

Los nombres del menú cambian según la marca del teléfono. Si no lo encuentras, busca “certificado” en el buscador de Ajustes.

  1. Abre esta página en Safari (no en Chrome) y descarga el certificado:
    Descargar certificado
    Pulsa Permitir cuando pregunte por el perfil de configuración.
  2. Abre Ajustes → Perfil descargado (arriba) → Instalar → escribe tu código → Instalar.
  3. Ve a Ajustes → General → Información → Ajustes de confianza de certificados y activa DECE-UETS-CA.
  4. Vuelve aquí y pulsa Ya lo instalé, verificar.

Todavía no se reconoce el certificado. Revisa los pasos y asegúrate de cerrar y abrir de nuevo el navegador. Si sigue sin funcionar, contacta a Sistemas.
